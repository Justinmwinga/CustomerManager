# Customer Manager

A simple JavaFX desktop application for managing customer records.

This project was created as a classroom laboratory exercise to demonstrate JavaFX controls, event handling, validation, observable collections, and TableView.

## Features

- Enter a customer's name
- Select a province
- Add customers to the table
- Display customers using a TableView
- Validate required input
- Delete a selected customer
- Confirm before deleting a customer
- Keyboard-friendly form navigation

## Technologies Used

- Java 21
- JavaFX 21.0.12
- Gradle 9.8
- JavaFX Controls
- JavaFX ObservableList
